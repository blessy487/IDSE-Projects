# 🌊 OCEAN RESCUE – THE DEEP SEA ADVENTURE

An interactive Data Science learning game for Jupyter (Pandas, NumPy, Matplotlib, Scikit-learn, IPyWidgets).

## Files
| File | Purpose |
|---|---|
| `Ocean_Rescue_Deep_Sea_Adventure.ipynb` | The complete game + documentation + playtesting section |
| `requirements.txt` | Python dependencies |

## Run it
```bash
pip install -r requirements.txt
jupyter lab Ocean_Rescue_Deep_Sea_Adventure.ipynb
```
Then choose **Kernel ▸ Restart & Run All**. The game appears under the cell titled "LAUNCH THE GAME".
Works in JupyterLab, Jupyter Notebook 6/7, VS Code and Google Colab (Python 3.9+).

## Notebook structure
1. Documentation (intro, objectives, learning objectives, libraries, how to play, missions)
2. Game code (dataset, state/HUD/animations, menu & ocean map, Missions 1-4, final report)
3. Launch cell
4. Playtesting (automated self-test, human checklist, playtest log, requirement coverage)
